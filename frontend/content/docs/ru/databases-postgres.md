# Управляемый PostgreSQL

## Зачем это нужно

Готовый инстанс Postgres для вашего приложения: создаёте базу, по желанию привязываете её к
приложению — строка подключения приезжает в приложение сама. Сервер патчить не надо, дампы
руками гонять тоже (бэкапы идут по расписанию, если их включить).

## Как создать базу

1. Откройте **Databases** → **Create Database**.
2. Заполните форму:
   - **Database Name** — имя ресурса в платформе (строчные буквы, цифры, дефисы).
   - **PostgreSQL DB Name** — имя самой базы внутри Postgres.
   - **App Reference** — необязательно: привязать реквизиты к конкретному приложению или
     оставить пустым, тогда база будет на уровне окружения и её смогут использовать несколько
     приложений.
   - **Backups** — переключатель (включён по умолчанию) с расписанием (раз в час или раз в
     сутки) и сроком хранения (7, 14 или 30 дней).
3. Нажмите создать — вас перебросит в **Operations**, где видно ход выделения ресурса.
4. Когда база готова, её карточка показывает размер и время последней синхронизации. По клику
   открывается страница с деталями.

## Как подключить приложение

Реквизиты доставляются в приложение как секрет в его пространстве имён и **в консоли не
показываются**. Ссылайтесь на них через переменные окружения приложения (например, задайте
`DATABASE_URL` в настройках переменных со scope `runtime`). Кнопки «скопировать строку
подключения» в интерфейсе нет — не ищите.

## Подводные камни

- **Восстановления из бэкапа в интерфейсе нет.** Бэкапы снимаются по расписанию, но
  восстановление сейчас идёт только через поддержку. Не считайте переключатель бэкапов полной
  гарантией восстановления.
- **Удаления тоже нет.** Созданную базу нельзя убрать из консоли — имена выбирайте
  внимательно, а для удаления пишите в поддержку.
- **Только PostgreSQL.** Управляемых MySQL и Redis в таком виде нет. Они существуют только как
  `ServiceDatabase` на серверах приложений с Docker Compose — это другой механизм, см.
  [Серверы приложений](app-servers-bring-your-own-vm.md).
- Пустой **App Reference** создаёт базу уровня окружения, к которой можно подключить любое
  приложение; заполненный привязывает базу и её секрет к одному приложению.

## Чего пока нет

- Восстановления из бэкапа своими руками (пока только через поддержку).
- Удаления базы.
- Метрик подключений и запросов в консоли.
- MySQL и Redis как управляемых ресурсов в облачных окружениях — только через `ServiceDatabase`
  на виртуальной машине.
