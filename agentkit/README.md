# agentkit

Общий слой для наших агентов. Сюда попадает то, что уже понадобилось дважды;
всё остальное живёт в самом агенте, пока не понадобится.

Статус: обёртка. Кандидат в платформу, но ещё не проверен на клиентском репо.
Разметка кусков и обоснование — `../docs/PLATFORM-DOGFOODING.md`.

| Модуль | Что делает |
|---|---|
| `humanize.py` | Ищет AI-метки в короткой реплике: слоп-фразы, разметка в чате, длинное тире, невидимый юникод, длина. Без модели |
| `evalspec.py` | Формат золотого набора (JSONL), валидация, раннер, сводка, гейт по сплиту |
| `skills.py` | Загрузка `agents/<имя>/core.md` и `domains/<домен>.md`, та же раскладка, что читает Go-рантайм |

Зависимостей нет, только стандартная библиотека.

```bash
cd agentkit && python3 -m unittest discover -s tests -q
```

## Почему правила, а не судья-модель

Проверка, которой нужна LLM, не встаёт в прегейт, не объясняет себя и плывёт
вместе с судьёй. Правило называет конкретный кусок, на котором сработало, и
его можно опровергнуть. Судейская модель имеет смысл поверх, никогда вместо.

## Почему сплиты — не украшение

`dev` для тюнинга, `holdout` для решения. Прогон `holdout` больше одного раза
на ревизию делает из набора зеркало: он начинает мерить подгонку, а не
годность.
