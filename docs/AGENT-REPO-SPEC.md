# Спецификация агентского репозитория (черновик v1)

Что должно лежать в репозитории, чтобы платформа могла проверить агента до
выката. Написана не в вакууме: ровно этот контракт выполняет наш собственный
монорепозиторий, и проверяет его тот же файл, который получит клиент.

Проверка называется `agentkit/repospec.py` и запускается без аргументов, кроме
корня репозитория:

```bash
python3 agentkit/repospec.py --repo .
```

Нужен только интерпретатор python. Ни ключей, ни сети, ни зависимостей: гейт,
которому нужен креденшл, не гоняется на каждом коммите, он получает
креденшл, потом таймаут, потом `|| true`.

## 1. Манифест `.dada/agent.json`

```json
{
  "version": 1,
  "agents": [
    {
      "name": "vibecoder",
      "agents_root": "tg-vibecoder",
      "cases": "tg-vibecoder/evals/persona/cases.jsonl",
      "holdout_threshold": 0.75
    }
  ]
}
```

| Поле | Смысл |
|---|---|
| `name` | имя агента, оно же имя каталога в `agents_root/agents/<name>/` |
| `agents_root` | каталог, внутри которого лежит `agents/` |
| `cases` | путь к золотому набору, JSONL |
| `holdout_threshold` | порог приёмки по `holdout`, число в `[0.5, 1]` |

Порог обязателен и живёт в файле. Порог в голове выбирается после прогона, и
тогда `holdout` становится декоративным.

JSON, а не YAML, по той же причине, по которой гейт model-free: зависимость
это то, что ломается ровно в тот день, когда проверка понадобилась.

## 2. Промпт разложен на ядро и домены

```
agents/<name>/core.md
agents/<name>/domains/<домен>.md
```

`core.md` — кто агент, чем он не является, как принимает решение отвечать или
молчать, и куда уходить за процедурой. Домен — одна процедура целиком.

Монолитный промпт оплачивается на каждом ходу целиком, и его куски расходятся,
потому что никто не видит, какой абзац несущий. Проверка ловит два вырождения:
домен, на который ядро ни разу не ссылается (мёртвый файл либо мёртвый рычаг),
и агента без доменов вообще.

## 3. Промпт подчиняется тому стилю, который проповедует

Ядро и домены проходят тот же детектор слопа, что и реплики агента: запрещённые
юникод-символы, длинное тире, шаблонные фразы. Текст в кавычках освобождён —
строка, которая запрещает фразу, обязана её назвать.

## 4. Золотой набор

JSONL, одна строка на кейс. Требования, которые проверяются механически:

- **не меньше 12 кейсов**, из них **не меньше 6 в `holdout`** и непустой `dev`;
- **не меньше 20% кейсов, где правильный ответ — молчание.** Набор, который
  всегда хочет ответа, не поймает бота, который не умеет заткнуться;
- **рубрика не противоречит флагу.** Рубрика вида «молчит либо одна нейтральная
  строка» при `should_reply: false` без `allow_silence`/`allow_reply` — дефект
  кейса: модель вечно будет валить кейс, который сама же прошла по его рубрике.

Последний пункт написан по следам: два прогона по модели из трёх мы потратили
на дефекты собственного набора, а не на дефекты агента.

`dev` — то, на чём крутят промпт. `holdout` — то, что смотрят один раз перед
выкатом. Тюнинг по `holdout` превращает эвал в зеркало.

## 5. Два уровня проверки, и это сознательно

| Уровень | Чем считается | Когда гоняется | Роняет ли мерж |
|---|---|---|---|
| `repospec.py` | без модели, stdlib | каждый мерж | да |
| бейкофф по `holdout` | вызовами модели | вручную перед релизом | нет, но без него не выкатывают |

Дорогую половину нельзя ставить в прегейт: ей нужен ключ, она стоит минуты и
она первой получает `|| true`, когда мешает. Дешёвая половина гарантирует, что
материал, который съест дорогая, хотя бы корректен.

Гейт гоняется без фильтра по изменённым файлам. Золотой набор протухает и
когда его никто не трогает.

## 6. Контракт доставки ответа

Это не про репозиторий, а про рантайм, но нарушение выглядит как дефект
агента, поэтому лежит здесь.

У агента, который имеет право молчать, должно быть **три различимых исхода**:
ответ, молчание, отказ. Ни один из них не выражается отсутствием значения.

У A2A нет пустого хода. То, чего модель не написала сама, рантайм добирает
результатом последнего вызова инструмента, и в чат уезжает `{"ok":true}`.
Поэтому молчание — это слово (`agentkit.ledger.SILENCE_SENTINEL`), а снимает
его тот, кто отправляет сообщение в мессенджер.

Симметрично: инструмент журнала не является каналом доставки. Запись
«ответил» без текста ответа отклоняется на входе в инструмент, а не постфактум
в отчёте.

## 7. Транспорт тул-сервера

Если агент носит с собой MCP-сервер как обычное приложение:

- сервер обязан быть **stateless**. Приложение поднимается в нескольких
  репликах, а streamable-http держит сессию в памяти того пода, который её
  открыл. Одна реплика дефект не чинит, а прячет до первого автоскейла;
- `/mcp` обязан требовать креденшл. Приложению по умолчанию выдаётся публичный
  домен, и без токена инструменты агента отвечают из интернета кому угодно.
