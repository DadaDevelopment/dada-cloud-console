## LATER — по триггерам

- **Box externalization** — триггер: первые внешние workflows, где app/VM-модель объективно хуже. Не убивать, не считать core. Warm pool (15.6% инфра-счёта при нулевом внешнем спросе) — кандидат на ужатие до триггера.
- **Автофикс наружу как ставка** — триггер: внешний юзер реально отдаёт агенту production operation loop. Планка валидации: ≥1 мерж из первых 5 внешних PR за 7 дней; 0/5 → механика «покажи, что работает» (фикс в staging), не «поверь коду».
- **Drift/reconcile для imported серверов** — триггер: imported workloads живут достаточно долго, чтобы drift стал болью.
- **Compose → managed migration funnel** («your VPS → Dada control → Dada managed») — красивая воронка H13, но только после доказательства входной ступени H06.
- **MCP расширение** — после реальных agent-operated workflows; вместе с CLI поверх одного API.
