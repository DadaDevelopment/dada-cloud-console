# Jurisdiction Requirements — Trading Platform Registration

## Overview

This domain covers jurisdictional requirements and regulations for clients registering on the trading platform. Use this when discussing:
- Supported countries and restrictions
- KYC/AML compliance requirements
- Regional licensing and regulations
- Restricted jurisdictions

## Supported Jurisdictions

### Tier 1 — Full Service Available
- United Kingdom
- European Union (excluding restricted countries)
- Australia
- Singapore
- United Arab Emirates

**Requirements:** Standard KYC (passport/ID + proof of address)

### Tier 2 — Limited Service
- Canada (excluding Quebec)
- Japan
- South Korea

**Requirements:** Enhanced KYC + tax residency documentation

### Tier 3 — Restricted
The platform does **not** accept clients from:
- United States (FATCA compliance)
- North Korea, Iran, Syria (OFAC sanctions)
- Russia, Belarus (current sanctions)
- Afghanistan, Myanmar (AML concerns)

## Common Client Questions

### "Can I register from [country]?"

1. Check the tier list above
2. If Tier 1/2 → proceed with registration
3. If Tier 3 → politely decline and explain regulatory restrictions
4. If unlisted → escalate to compliance team

**Script:**
"We currently support clients from [tier]. To complete your registration, you'll need [requirements]. Would you like to proceed?"

### "I'm traveling, can I use my account?"

- **Yes** if registered jurisdiction remains primary tax residency
- **No** if relocating permanently to restricted jurisdiction
- Must update address within 30 days of permanent move

### "I have dual citizenship"

- Use **tax residency** jurisdiction, not citizenship
- If one citizenship is restricted → use the non-restricted one
- Must provide tax residency documentation

## Escalation Triggers

Escalate to compliance team if:
- Client claims diplomatic immunity or special status
- Conflicting jurisdiction information (VPN, address mismatch)
- Client from Tier 3 requesting exception
- Suspected sanctions evasion
