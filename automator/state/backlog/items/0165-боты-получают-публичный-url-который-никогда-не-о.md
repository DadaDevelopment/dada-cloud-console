- [ ] Боты получают публичный URL, который никогда не ответит (3 из 15 доменов). Детект порта этот класс не лечит: у бота нет ни EXPOSE, ни веб-фреймворка → `Port=nil` → фолбэк 8080 → домен + серт + красный баннер url-алерта на ЖИВОМ работающем боте. То есть платформа говорит юзеру, что его рабочий бот сломан. Нужен продуктовый ход: при `Port==nil` из детекта предлагать worker-режим (без домена), либо `app_url_watcher` при устойчивом «нет слушателя» звать «похоже это воркер — убрать публичный адрес?». НЕ делать дефолтом молча: `renderer.go:426` уже корректен (`Enabled: spec.Port > 0`), ломать нечего.
