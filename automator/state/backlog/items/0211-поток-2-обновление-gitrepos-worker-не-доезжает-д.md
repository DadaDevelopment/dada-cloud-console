- [ ] 🟠 ПОТОК-2: ОБНОВЛЕНИЕ `git_repos.worker` НЕ ДОЕЗЖАЕТ ДО СНАПШОТА ПРИ РЕДЕПЛОЕ (sess-0806n, [code], хвост fanvk) — `doDeployImageVersion` (`gitops-agent/internal/worker/dbwatcher.go:~1785`) читает port/worker из снапшота, а не из `git_repos`, поэтому исправленный детектором флаг у УЖЕ пострадавшего аппа не применяется никаким действием юзера. Это и есть механизм, из-за которого «три живых аппа с фантомным портом» не чинятся сами. Решать вместе с пунктом про три аппа.
