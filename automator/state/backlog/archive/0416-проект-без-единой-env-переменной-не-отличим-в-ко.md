вплоть до 2026-08-19 23:03 — то есть пересобирал снова и снова, ни разу не
добавив переменную. Ни одного действия с env в его следе нет.

а бот их требует». Кандидат на рычаг: на странице аппа с крашем по отсутствующей
переменной — прямое предложение добавить её (у нас уже есть текст ошибки из
логов), плюс подсказка «в соседнем проекте эта переменная есть».
