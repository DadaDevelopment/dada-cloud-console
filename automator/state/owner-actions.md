По пути провайдера эти адреса не отвечают. Перебраны и исключены: `--interface en0`, `utun3..utun6`, оба локальных байпас-прокси (8899, 8901), голый curl — везде `000`.

**Что просит рутина.** Один из двух вариантов, оба требуют пароля владельца, поэтому сделать сама не может:
```
sudo route delete 83.222.27.62
sudo route delete 155.212.223.198
```
либо убрать эти хосты из списка байпаса split-tunnel в AmneziaVPN.

**Цена бездействия.** 15 созревших экспериментов (E73, E81, E93, E113, E115, E117—E121, E123—E125, E138, E149) четвёртый цикл записываются как `unmeasured`; доставка последних коммитов в прод не подтверждается образом пода, а только фактом коммита; анализ путей `audit_events` не делается вовсе. Каждый цикл при этом продолжает отгружать код вслепую.
